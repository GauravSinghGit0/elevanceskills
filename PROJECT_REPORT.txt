1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Cineva is an enterprise-grade cinema ticketing and theater management web
application modeled after industry-leading platforms such as BookMyShow and
AMC Theatres. The platform provides a modern, cinematic, dark-themed user
experience for movie lovers to discover films, watch official high-definition
trailers, select exact seats across multi-tiered theater auditoriums, order
gourmet food court concessions, and complete checkout with an authentic UPI /
QR code payment simulation and Razorpay gateway.

Upon completing a booking, Cineva automatically:
- Generates a cryptographically signed, print-ready PDF admission pass with
  a verifiable QR code.
- Dispatches a personalized confirmation email with the PDF attached via Gmail
  SMTP using Celery background workers.
- Records transactions for auditing and updates live inventory with zero double-
  booking concurrency protection.

The platform includes a comprehensive, responsive Administrator Dashboard
allowing cinema managers to add/remove movies, assign screenings to auditoriums,
manage seat layouts, review food court orders, and analyze box office metrics.

3. SYSTEM ARCHITECTURE & TECHNICAL SPECIFICATIONS
--------------------------------------------------------------------------------
A. Backend Framework:
   - Django 3.2 LTS operating on Python 3.12.3.
   - Clean Model-View-Template (MVT) architecture with dedicated service layers:
     * PaymentGatewayService: Handles order creation, HMAC verification, retries.
     * SeatLockService: Implements high-concurrency atomic row locks and 2-minute holds.
     * TicketGeneratorService: Produces PDF admission passes and dynamic QR codes.
     * TheaterSeatingService: Builds multi-tiered auditorium layouts.
     * MovieQueryService: Optimizes database queries to eliminate N+1 bottlenecks.

B. Database Strategy:
   - Cloud Production: Neon Serverless PostgreSQL (AWS us-east-2) with PgBouncer
     connection pooling.
   - Fallback / Dev: SQLite3 bundled database with automated replication into
     /tmp/db.sqlite3 for Vercel's ephemeral serverless container filesystem.
   - Test Isolation: Automated in-memory SQLite runner ensuring lightning-fast
     local test suite execution.

C. Static & Media Asset Delivery:
   - WhiteNoise (CompressedStaticFilesStorage) delivers static files directly
     through the application layer in production with Gzip compression and
     unique cache fingerprints.
   - Production static collection verified with 129 files and 125 pre-processed
     assets.


4. CORE FUNCTIONALITIES & INNOVATIONS
--------------------------------------------------------------------------------
A. Real Movie Catalog & Curated Repertory:
   - 19 fully populated cinema releases across Action, Sci-Fi, Drama, Thriller,
     and Animation.
   - High-resolution posters, certifications (UA, U, A), ratings, and durations.
   - Embedded HD YouTube trailer modals with keyboard escape support and
     animated play triggers.

B. Interactive Cinema Seating & Concurrency Protection:
   - 1,315 seats configured across 8 flagship theaters and 16 screens in major
     metropolitan hubs (Mumbai, Delhi, Bengaluru, Hyderabad).
   - 5 Pricing Tiers:
     1. Recliner VIP Lounge:         ₹350.00
     2. Premium Prime:               ₹250.00
     3. Executive Club:              ₹200.00
     4. Silver Plus:                 ₹160.00
     5. Classic D-Cinema:            ₹120.00
   - 2-Minute Reservation Hold: When a user selects a seat, a countdown timer
     activates. The seat is locked at the database level with 'select_for_update'.
     If payment is not finalized in 120 seconds, the seat is automatically
     released for other patrons.
   - Micro-Interaction Animations: Tactile pop animations (seat-selected-pop)
     on seat click, animated projector light beams (screen-glow-animated),
     and responsive hover states.

C. Gourmet Food Court & Snack Ordering:
   - Category filtering: All, Popcorn, Combos, Snacks, Beverages.
   - Interactive item cards with live counter pills (+ / -).
   - Dynamic real-time cart recalculation including ticket subtotal, snack total,
     and 10% multiplex convenience fee.

D. Authentic Payment Gateway & Scannable UPI / QR Simulation:
   - 100% Real Scannable UPI QR Code: Encodes standard UPI specification
     (upi://pay?pa=cinevatickets@okaxis&pn=CinevaCinema&am=AMOUNT&cu=INR).
     Compatible with Google Pay, PhonePe, Paytm, BHIM, Cred, and mobile cameras.
   - 1-Click Instant Test Mode: "Simulate Successful Payment (1-Click Test)" button
     allows rapid testing in sandbox environments.
   - Razorpay Modal Integration: Production-ready Razorpay checkout with test
     key support (rzp_test_TkuUcn0OX3jYly) and HMAC-SHA256 signature verification.

E. Ticket Generation & Multi-Channel Delivery:
   - ReportLab PDF generator produces authentic admission passes with barcode,
     seat details, auditorium directions, terms of entry, and verification QR code.
   - Email Confirmation: Sends rich HTML emails with PDF ticket attachments
     via Gmail SMTP. Celery worker handles queueing with an automatic daemon
     thread fallback for environments without Redis.

F. 10-Minute Show Cut-off & Past Showtime Enforcement:
   - Online ticket booking strictly shuts down 10 minutes prior to show start time.
   - Showtimes in the past or within the 10-minute cut-off are rendered locked
     with strike-through labels and security badges.
   - Comprehensive server-side protection blocks seat selection, AJAX locks,
     and transaction checkout attempts for closed screenings.

G. 100% Instant Ticket Cancellation & Refund Workflow:
   - Self-service cancellation and refund directly from User Profile.
   - Restores seat inventory atomically to ensure zero stale reservations.
   - Telemetry tracks refunded transactions and revenue across analytics suite.
   - Voids admission passes and invalidates QR gate tokens immediately.


5. DATABASE SCHEMA & DATA MODEL DETAILS
--------------------------------------------------------------------------------
The database schema comprises 13 interconnected models:

1. Genre:
   - id, name, slug.
2. Language:
   - id, name, code.
3. CastMember:
   - id, name, role, photo.
4. Movie:
   - id, title, slug, description, short_description, release_date, duration,
     rating, age_certification, poster, trailer_video_id, is_active.
   - Many-to-Many relations with Genre, Language, and CastMember.
5. MovieImage:
   - id, movie_id, image, caption, is_backdrop.
6. Theater:
   - id, movie_id, name, city, location, time, sound_system.
7. Screen:
   - id, theater_id, screen_number, name, total_seats.
8. ShowSchedule:
   - id, theater_id, movie_id, screen_id, start_time, end_time, price, status.
9. Seat:
   - id, theater_id, screen_id, seat_number, row, number, tier, price,
     is_booked, locked_by_id, lock_session_key, locked_until.
10. Payment:
    - id, order_id, transaction_id, gateway, payment_method, status, amount,
      currency, user_id, movie_id, theater_id, show_id, seat_ids, seat_numbers.
11. Booking:
    - id, user_id, seat_id (OneToOne with Seat), movie_id, theater_id, show_id,
      payment_id, booked_at.
12. Review:
    - id, movie_id, user_id, rating, comment, is_verified_viewer, created_at.
13. ReviewReport:
    - id, review_id, reported_by_id, reason, status, created_at.

8. LOCAL SETUP & RUNNING INSTRUCTIONS
--------------------------------------------------------------------------------
1. Clone Repository:
   git clone https://github.com/GauravSinghGit0/elevanceskills.git
   cd elevanceskills

2. Create Virtual Environment:
   python3 -m venv venv
   source venv/bin/activate

3. Install Dependencies:
   pip install -r requirements.txt

4. Configure Database & Migrations:
   python manage.py migrate

5. Initialize Superuser:
   python manage.py setup_admin

6. Start Development Server:
   python manage.py runserver 0.0.0.0:8000

7. Access Application:
   - User Portal:  http://127.0.0.1:8000/
   - Admin Suite:  http://127.0.0.1:8000/movies/admin/


9. PRODUCTION DEPLOYMENT (VERCEL + NEON)
--------------------------------------------------------------------------------
The project is pre-configured with:
- vercel.json: Routes static assets to distDir 'staticfiles' and proxy routes
  to 'bookmyseat/wsgi.py'.
- build_files.sh: Installs dependencies with PEP 668 flags and runs collectstatic.
- staticfiles: 129 compiled static assets committed directly to the repo for
  guaranteed zero-downtime builds.

To deploy on Vercel:
1. Import repository 'GauravSinghGit0/elevanceskills' in Vercel Dashboard.
2. Select Framework Preset: 'Other'.
3. Copy environment variables from 'vercel_env.txt' into Vercel Project Settings.
4. Click Deploy.
